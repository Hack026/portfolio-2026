# Padmanava Das Portfolio

This is the source for my portfolio site. It uses HTML, CSS, and JavaScript, with Vite for local development and production builds.

## Run locally

```cmd
npm install
npm run dev
```

## Build

```cmd
npm run build
npm run preview
```

The build goes into `dist/`. Deploy that folder, not the project root. Source maps are disabled, and the JavaScript is minified and obfuscated. This makes it less readable, but anything sent to a browser can still be inspected.
